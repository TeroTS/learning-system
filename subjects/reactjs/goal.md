# React.js

## Goal
Learn React.js fundamentals efficiently using TypeScript, understanding how React works and applying practical modern development patterns. Focus on React.js, not TypeScript instruction. Demonstrate the ability to build and test components and implement routing, forms, and REST API data handling through separate tasks; no final independent application is required.

Requested topics:
1. React architecture, core concepts, and declarative UI
2. React components and component composition
3. JSX and TSX syntax
4. Props and passing data between components
5. Rendering, reconciliation, and the virtual DOM
6. Conditional rendering
7. Rendering lists and using keys correctly
8. Event handling and user interactions
9. State management with useState
10. State updates, immutability, and batching
11. Component lifecycle and rendering behavior
12. Side effects and useEffect
13. Effect dependencies and cleanup
14. Forms, controlled components, and input handling
15. Lifting state up and sharing state between components
16. useRef and working with DOM elements
17. useMemo and useCallback
18. Custom hooks and reusable component logic
19. Context API and useContext
20. Client-side routing with React Router
21. Fetching data from REST APIs
22. Loading, error, and empty states
23. Component styling and CSS fundamentals in React
24. Testing React components with React Testing Library
25. Debugging with React Developer Tools
26. Common React pitfalls and best practices
27. Modern React features and recommended development patterns

Use TypeScript for all coding examples and exercises.

## Level
Agent judgement: initial React beginner. Recognizes components as UI units that may include event handlers and supplied paragraph TSX, but could not define a Greeting component unaided. Other React skills remain unverified. Reports experienced software engineering, JavaScript, TypeScript, Node.js, and backend development experience, and a small AI-assisted React todo app; no unaided React development reported. These background claims were not independently assessed.

## Deadline
None

## Test Format
Small coding tasks and explanations for each topic, completed unaided. Separate tasks collectively demonstrate component building and testing, routing, forms, and REST API data handling. No final independent application required.
