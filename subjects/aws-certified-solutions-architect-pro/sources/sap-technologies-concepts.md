

# Technologies and Concepts

+ Cost management
+ Database
+ Disaster recovery
+ High availability
+ Management and governance
+ Microservices and component decoupling
+ Migration and data transfer
+ Networking, connectivity, and content delivery
+ Security
+ Serverless design principles
+ Storage
